6. PERFORMANCE PHILOSOPHY
This site will use heavy visual assets.
Performance must be designed from the beginning.

Requirements:
- lazy-load heavy section assets shortly before they enter viewport
- preload only what is necessary for first meaningful paint and hero sequence
- render only active / near-active scenes where possible
- pause offscreen animation
- pause animation when document is hidden
- reduce animation density on mobile
- reduce DPR / resolution where appropriate
- prefer compressed WebP/AVIF where suitable
- use transparent PNG/WebP only when transparency is necessary
- avoid huge uncompressed video backgrounds
- use sprite sheets or short optimized loops where better
- use content-visibility where useful
- preserve fast interaction and readable content if artwork is still loading

Do not let artistic ambition create a sluggish page.

- rubber
- plastic cards

A. initial stillness

~1.2–2.0s

~0.8–1.5s

Keep:
- fonts swappable
- art assets swappable
- animation timing tunable
- scene colors tokenized
- motion amplitudes configurable
- section boundaries editable

Kiarash wants to evaluate the artistic result, not be trapped by rigid implementation.

41. WHAT MUST NOT HAPPEN
Avoid:
- generic black developer portfolio
- huge neon gradients
- futuristic glass UI everywhere
- random cyan accent language
- overly corporate tone
- resume-like section design
- repeated generic cards
- every section using same layout
- every section using same font
- every section using same art style
- abrupt theme swaps
- excessive parallax
- overused particle effects
- overused mouse interaction
- cursor gimmicks
- clickable fish
- game-like navigation
- physics for physics’ sake
- procedural art that looks sterile
- photorealistic fish
- fish with wrong side-view perspective
- mobile as simple desktop scaling
- pop-up-book effect on every section
- animation that blocks reading
- long forced intro
- destructive DOM changes
- inaccessible text
- loading all heavy assets immediately
- copyright-heavy direct asset reuse
- placeholder Lorem Ipsum
- rewriting Kiarash’s identity into generic marketing copy

42. QUALITY BAR
The result should feel closer to:
- an interactive illustrated book
- a digital exhibition
- an art-directed title sequence
- a carefully animated environmental portfolio

than to:
- a dashboard
- a template
- a landing page
- a game UI
- an agency clone

When deciding between:
A. technically clever
and
B. visually beautiful

choose B,
unless B makes the site unusable or unmaintainable.

When deciding between:
A. more interaction
and
B. better atmosphere

choose B.

43. SUCCESS CRITERIA
The redesign is successful if:

1. The site feels unmistakably personal.
2. The visual worlds feel intentional rather than random.
3. The pond is beautiful even when nothing dramatic happens.
4. The opening name-drop sequence is memorable but short.
5. The Hobbit-home interaction feels delightful.
6. Gollum feels like a creature living in the environment, not a widget.
7. The Skills scene feels monumental.
8. Work 1 conveys scale and sublime fantasy.
9. Work 2 feels like stained glass, not cards with filters.
10. The Wall/map section genuinely feels like paper architecture unfolding.
11. Typography changes support each world.
12. The navigation remains understandable.
13. The site remains readable.
14. Mobile feels intentionally adapted.
15. Performance remains acceptable despite the artwork.
16. The site does not resemble a generic CV.
17. The site can still be maintained and extended later.
18. All existing important content remains represented.
19. The result demonstrates both visual taste and frontend ability.
20. The visitor remembers the experience after leaving.

45. FINAL NORTH STAR
The site should feel like:

“A personal fantasy journey made by a developer who understands both code and art.”

The visitor begins at a Persian-turquoise living pond,
moves into a pastoral fantasy world,
encounters high-resolution pixel-art characters,
passes a monumental fantasy city,
enters a dark sublime landscape,
moves through stained glass,
then reaches cartographic / paper-diorama fantasy spaces,
all while the real portfolio content remains readable and meaningful.

The site should be surprising,
but never confusing.

Beautiful,
but not decorative for decoration’s sake.

Technically ambitious,
but not technically self-indulgent.

The world should feel alive,
but not demand constant interaction.

The portfolio should introduce Kiarash by showing his taste and imagination,
not by behaving like a résumé.
